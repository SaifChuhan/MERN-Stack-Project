# 📚 MERN Stack Book Management App

A full-stack book management application with complete CRUD functionality, built using the MERN stack (MongoDB, Express, React, Node.js). Features a responsive UI with modal interactions and real-time database updates.

## 🚀 Features

- **Full CRUD Operations**:
  - Create new books with form validation
  - Read books in grid/list views
  - Update existing book details
  - Delete books with confirmation
- **Modern UI**:
  - Responsive design with Tailwind CSS
  - Interactive modals for book operations
  - Loading spinners and error handling
- **Backend API**:
  - RESTful API endpoints
  - MongoDB database integration
  - CORS enabled for cross-origin requests

## 🛠️ Technologies Used

**Backend**:
- Node.js
- Express.js
- MongoDB (Mongoose ODM)
- CORS

**Frontend**:
- React.js
- Vite
- React Router
- Tailwind CSS
- Heroicons
