# 📚 MERN Stack Book Management App

A full-stack CRUD application built step-by-step using the **MERN stack** (MongoDB, Express, React, Node.js). This project was developed as a learning journey from setting up a Node.js backend to building a responsive React frontend with full CRUD functionality for managing books.

---

## 🧠 What This Project Covers

This app lets users **Create**, **Read**, **Update**, and **Delete** books. It was built incrementally through 22 focused lessons, combining backend and frontend development, with improvements to user experience.

### ✅ Completed Lessons

- **Backend with Node.js, Express & MongoDB:**
  - ✔️ Lesson 01: Setup Node.js project from scratch
  - ✔️ Lesson 02: Create a basic HTTP route
  - ✔️ Lesson 03: Integrate MongoDB using Mongoose
  - ✔️ Lesson 04: Define a Mongoose Book model
  - ✔️ Lesson 05: Save new books to the database
  - ✔️ Lesson 06: Retrieve all books
  - ✔️ Lesson 07: Retrieve a single book by ID
  - ✔️ Lesson 08: Update a book by ID
  - ✔️ Lesson 09: Delete a book by ID
  - ✔️ Lesson 10: Refactor using Express Router
  - ✔️ Lesson 11: Handle CORS policy for frontend/backend connection

- **Frontend with React, Vite & Tailwind CSS:**
  - ✔️ Lesson 12: Initialize React project with Vite & Tailwind
  - ✔️ Lesson 13: Add React Router for SPA routing
  - ✔️ Lesson 14: Display a list of books
  - ✔️ Lesson 15: View book details page
  - ✔️ Lesson 16: Add form to create a new book
  - ✔️ Lesson 17: Add form to edit a book
  - ✔️ Lesson 18: Delete a book from the UI
  - ✔️ Lesson 19: Display books as cards (grid layout)
  - ✔️ Lesson 20: Refactor Book Card as a reusable component
  - ✔️ Lesson 21: Add modal popups for book interactions
  - ✔️ Lesson 22: Improve UX with alerts and confirmation prompts
